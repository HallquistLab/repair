# REPAIR numerical reference fixtures

`repair-reference.rds` contains six synthetic inputs and expected results
produced independently of this R package. Metadata in the RDS records source
paths, hashes, source-repository commit, estimator settings, and R version.

The companion `blup_unshrinking` repository at commit
`b1f09f430d2214d5c4c8815b1386b62cb4ae159e` supplied:

- `R/fuller_mlm.R`: full M-MOM matrices and intermediate quantities;
- `R/stage2_estimators.R`: primary simulation coefficient, SE, and interval;
- `vig_hallquist_2026/analysis/fuller_algebra_audit_simulation.R`: independent
  algebra-audit coefficient, SE, and interval.

Cases cover predictor-only, outcome-only, both-sided, heteroskedastic, correlated
error, and weak-information inputs. The weak-information case distinguishes the
manuscript's modified covariance bread from the former unregularized bread.

Ordinary tests read the fixture without the sibling repository. Regeneration is
an intentional maintenance action using `dev/generate_repair_fixtures.R`; inspect
that script's usage and review any resulting fixture change. Do not regenerate
expected outputs from the package being tested.


## Observation-to-inference fixtures

`inst/extdata/nlme-workflow-reference.rds` contains three single-model nlme
reproduction cases, generated by `dev/generate_nlme_fixtures.R`.
`inst/extdata/multimodel-workflow-reference.rds` contains two dual-process cases,
generated by `dev/generate_multimodel_fixtures.R`: independent scoring errors and
supplied nonzero cross-model scoring-error covariance. Both generators additionally
use `R/blup_helpers.R` for production likelihood-only scores. Each fixture records
source hashes and versions; neither generator loads the package being tested.

The multi-model cases preserve within-model intercept/slope covariance and test
both computation backends from raw repeated observations through coefficients,
SEs, covariance matrices, and intervals. The supplied cross-error case propagates
a known residual correlation of 0.25 with fitted marginal scales through the
score operators. Tests also verify the dual-process population predictor/outcome
SD ratio used for reporting. These synthetic per-dataset cases are not the
published Monte Carlo tables. See `dev/multimodel-validation.md` for the contract
and `vignettes/multiple-models.Rmd` for the executable public workflow.
